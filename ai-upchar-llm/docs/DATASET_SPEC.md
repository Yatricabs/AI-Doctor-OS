# Dataset specification

Every example has an immutable id, task type, language, conversational messages,
source metadata, license, quality status, and privacy review. Supported tasks
cover knowledge, semantic extraction, context reasoning, adaptive questioning,
safety, clarification, multiple problems, medication effects, diagnosis
provenance, summarization, evidence interpretation, and preference comparison.

Patient-reported diagnoses remain separate from confirmed diagnoses. Targets
must not infer diagnoses from symptoms. English, Hindi, Hinglish, and mixed input
are first-class language labels.
